# E-Commerce Web Application

A full-stack e-commerce web application built from scratch using **React**, **Node.js**, **Express.js**, and **MySQL**.

This project is part of my journey to strengthen my full-stack development skills by building a real-world application while focusing on writing clean, maintainable code and understanding every concept behind the implementation.
